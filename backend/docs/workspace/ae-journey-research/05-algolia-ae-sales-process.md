# Algolia AE Sales Process — FY27 Field Guide (PRIMARY SOURCE)

Source: `docs/Algolia/AE Sales Process -  FY27 Field Guide.PDF` (8pp, CONFIDENTIAL, Internal Use Only). This is the **real, authoritative** Algolia AE motion — supersedes generic web research on methodology. Tier-1 signal.

## The spine: a 5-stage gated pipeline. NEVER skip a stage.

| Stage | Duration | Enter when | Exit gate (must-have) |
|---|---|---|---|
| **PREP** Research & Prep | Before every call | Any new opp or upcoming call | Tools run, research complete, goals defined |
| **SS1** Introduction | ~30 min, **no slides** | Prep complete, Algospy checked | Both Biz + Tech POC confirmed; quantifiable pain shared; next step scheduled |
| **SS2** Deep Discovery (Tech + Merch) | 60 min | SS1 exit met; SE pre-call done | Vision-to-Value delivered; eval path confirmed; PIE buy-in secured |
| **SS3** POC Ph1 — Custom Demo + Go-Live | 90 min | PIE built; pitch deck ready; impl plan drafted w/ Post-Sales | Roles defined; integration complexity surfaced; impl review complete |
| **SS4** Scoping & Proposal | Ongoing | All prior gates clear; no T-shirt sizing convos still open | ROI confirmed; proposal delivered; commercial terms anchored to impact |

Each stage = Enter requirement → Before-call prep → Goals → framing language → **Exit criteria (hard gate)**. The gates are the product's backbone.

## Algolia-specific vocabulary PRISM MUST speak

- **C.io = Constructor.io** — THE competitor. "Assume C.io is in the deal if ICP of a certain size." AE must know the C.io counter-narrative cold.
- **AI Sales Toolkit** — the tool AEs are told to "run a high-level search audit" with in PREP/SS1. **← THIS IS PRISM.**
- **Algospy (Chrome plugin)** — detects Algolia / C.io beacon on prospect site. **← PRISM's detect-search already does this.**
- **Value Prompter** — qualification/value tool; AE must "get answers to the Value Prompter" (SS1) and "get ALL Value Prompter answers to build the Anxiety Statement" (SS2). Has a "What We Heard" slide.
- **Vision-to-Value** — speech/deliverable built in SS2, delivered to create the gap between current and future state.
- **Anxiety Statement / Anxiety Question** — built from Value Prompter answers (SS2), addressed + confirmed in SS3. The emotional engine of the deal.
- **PIE = Pre-Implementation Environment** (a.k.a. Customer Playbook). Built in SS3 via internal PIE Playbook (Wk1 Demo Vetting → Wk2 Innovation Sprints → Wk3 Impl Plan).
- **MegGPT** — internal GPT for merch context.
- **Implementation Explorer / Customer Implementations + Slackbot** (#cust/#sales/#AE) — find 2-3 relevant live customer proofs.
- **T-shirt sizing** — rough sizing only; NO detailed scoping/pricing before SS4.
- **Enterprise Foundation** — positioning: SLA, uptime, proactive partnership — "not just product."

## Stage prep + artifacts (what PRISM feeds each stage)

**PREP (every call):** AI Sales Toolkit audit · Algospy (Algolia/C.io beacon) · Customer Implementations · SFDC/Gong review · Slackbot intel · name-drops for tech stack + vertical · Value Prompter "What We Heard" slide · MegGPT merch context · pull C.io competitive brief.

**SS1 (intro, no slides):** high-level search audit · 2-3 relevant customer impls · Algospy C.io check. Framing scripts (verbatim): *"Algolia works best when both tech and business teams work together."* / *"We're the only solution that's both technically flexible AND easy for business teams."* / *"If you only approach from one side — tech or merch — there are better options."* **Green/Yellow/Red flags** for qualification.

**SS2 (deep discovery):** 25min Technical (Search) + 25min Business (Merch/Category/Browse/Agents) + 5min Vision-to-Value. Ask 3 WHYs per pain. Merchandising Discovery Guide + General Discovery Guide (BANT, MEDDPICC). Output = Vision-to-Value + Anxiety Statement.

**SS3 (custom demo):** Competitive Pitch (15) + PIE demo (50) + Impl Plan (15). Pitch framework: **Anxiety Statement → 3-5 Algolia Differentiators → Differentiated Customer Examples.** Theme: "The How vs the What." AE maps every visual to requirements ("Here's what you saw / why it matters / what's next").

**SS4 (scoping & proposal):** Pre-Proposal Call (30min) validates assumptions. ROI anchored to measurable lift. **C.io counter-narrative table** (know cold):
- "3% ROI Guarantee" → *3% is table stakes — they control the metrics. Ask: value of 4 min vs 43 min downtime/month?*
- "It's free" → *Not free — factored into cost, and you lose control of your go-live.*
- "Consumption pricing too expensive" → *Eliminate consumption concerns term 1, right-size after we know usage.*
Closing frame: No risk · Easy to adopt · Trusted partnership · Accelerates time-to-value.

## IMPLICATIONS FOR THE PRISM AE UI — the reframe

1. **The AE journey is NOT "one pre-call brief." It's a stage-aware deal cockpit** mirroring PREP→SS1→SS2→SS3→SS4. PRISM should know which stage a deal is at and surface stage-appropriate prep, framing language, and the exit-gate checklist.
2. **PRISM IS the "AI Sales Toolkit"** the field guide already mandates in PREP/SS1 — plus Algospy (detect-search). This is the product's true home in the workflow; it's not a generic intel tool, it's the sanctioned prep engine. Huge adoption tailwind: the process already tells AEs to use it.
3. **The gate checklist is the backbone surface** — green/amber/red, exactly like the doc's Exit Criteria checklists. PRISM can track gate readiness and warn "don't move to SS2 without X."
4. **The 60-sec brief = the PREP/SS1 view:** search audit score + Algospy (Algolia/**C.io** detection) + 2-3 relevant customer impls + C.io competitive brief + Value Prompter "What We Heard." Maps almost 1:1 to existing PRISM modules.
5. **Drill-to-artifact set is stage-ordered**, and each maps to a real Algolia deliverable: SS1 flags → SS2 Discovery Guides + Vision-to-Value + Anxiety Statement → SS3 Competitive Pitch + PIE + Impl Plan → SS4 ROI model + C.io counter-narrative + proposal.
6. **C.io (Constructor.io) is the competitive spine.** Detect it (Algospy/detect-search), and arm the AE with the verbatim counter-narrative table at SS4. The existing "Golden Angle" (competitor uses Algolia) and this C.io counter-play are the two competitive pillars.
7. **PRISM should help BUILD the named deliverables**, not just inform: Value Prompter answers, Vision-to-Value, Anxiety Statement, Competitive Pitch, ROI model. These are the artifacts that open in the panel.

**Net:** the AE surface should be organized around the **deal's current stage + its exit gate**, with the conversation/brief adapting per stage — not a single static brief. This is the functional correction the founder was pointing at.
