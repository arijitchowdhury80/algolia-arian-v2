# Internal Audit Deliverables — Catalog for the AE Journey

Purpose: catalog the sales artifacts the existing Algolia search-audit pipeline already produces, so the PRISM AE journey is grounded in artifacts that already win deals. Read-only research. Every deliverable below is generated by an installed skill under `~/.claude/skills/` and is already mapped to a UI section in the PRISM IA spec (`docs/specs/information-architecture-v2.md`).

## 1. SPA / Interactive Audit Site — `{slug}/index.html`

- **Purpose:** The flagship interactive deliverable. A single-page app rendered deterministically from `audit-data.json` (Claude never writes layout HTML; the renderer `render-audit.ts` does). 5 tabs: summary, account, findings, case, playbook.
- **Contents (sections):** Company snapshot (animated stats), speedometer score gauge, 10-dimension findings with annotated screenshots, "In Their Own Words" exec quotes paired to audit gaps, competitive positioning matrix, ROI funnel, ABX sequence, recommended first play. Per-tab personalized subtitles (`tab_subtitles`, `recommended_first_play` fields).
- **Audience:** AE / SE / BD — used live in the meeting as the walkthrough surface (collateral-schedule lists it as the "Meeting" touch).
- **Sales-cycle stage:** Discovery → demo meeting (the artifact you screen-share).

## 2. AE Action Report — `{slug}/ae-report.html` + AE Pre-Call Brief `{slug}-ae-precall-brief.md`

- **Purpose:** AE-facing internal prep doc. NOT for the prospect. Every data point carries an inline source hyperlink (`REFERENCE.md` Step 5d).
- **Contents (10 sections):** (1) Executive Cheat Sheet — revenue+margin zone, business model, digital focus, top gap, opportunity+ROI; (2) Financial Profile 3-yr trend; (3) Key Executives w/ tenure+LinkedIn; (4) Recent News & Trigger Events; (5) Audit Highlights — top 3 findings w/ screenshot+query+result; (6) 6-8 Discovery Questions; (7) Stakeholder Targets (buying committee map); (8) Pilot Strategy (margin-zone-aware scope, KPIs, budget framing); (9) Competitive Context (golden angle); (10) "Speaking Their Language" — discovery Qs in the prospect's own SEC/earnings language.
- **Audience:** AE.
- **Sales-cycle stage:** Pre-call / discovery prep. **This is the core AE pre-call artifact.**

## 3. AE Playbook — `{slug}-playbook.md` (merged AE brief + sales plays)

This is the single most AE-targeted artifact at the pre-call/discovery stage. Generated by `algolia-synth-sales-plays`, grounded entirely in the prospect's own exec quotes — "a playbook without exec quotes is a template; do not ship a template."

- **Contents (6 sections):**
  - **BLUF header (30-second pre-call read):** Signal tier (HOT/WARM/COLD), top angle (the Challenger insight), key exec + contact route, Partner Play (warm intro if SI partner exists), most urgent dated signal.
  - **Top 5 Talking Points:** each = hook in prospect's own earnings-call language + what-we-found (exact query + result) + verbatim exec quote w/ speaker/title/source/date + competitor proof + exact opening line + expected reaction. Every point must cite an exec quote.
  - **Discovery Questions (SPIN-structured):** skips Situation Qs (already known from audit), leads with Implication (3) + Need-Payoff (2) + Problem confirmation (1). Each has branch logic: if engaged / if skeptical / if deflecting, plus a qualification signal.
  - **MEDDPICC Gap Map:** 8-row table (Metrics, Economic Buyer, Decision Criteria, Decision Process, Paper Process, Implication of Pain, Champion, Competition), each POPULATED/PARTIAL/UNKNOWN with evidence + AE action.
  - **Objection Handling:** min 4 (built-in-house / too-expensive / locked-in-with-vendor / not-a-priority), each = Objection → Response → Pivot → Fallback.
  - **Power Map:** name / title / role-in-deal / relationship / approach, tiered (Tier 1 Champion = economic buyer, Technical Buyer, Coach, Blocker).
  - **Partner Angles (Section 6):** priority order — HIGH-confidence SI warm intro > tech-partner co-sell > Golden Angle > cold outbound.
- **Audience:** AE / BDR / Partner.
- **Sales-cycle stage:** Pre-call → discovery → qualification (MEDDPICC fills as the deal progresses).

Note: `audit-report/REFERENCE.md` lines 731-743 also describes a playbook variant with ROI-framing-by-scenario and a 3-phase Pilot Blueprint (Foundation → Optimize → Scale w/ per-phase KPIs).

## 4. Battle Card — `{slug}/battle-card.html`

- **Purpose:** Competitive positioning, one card per competitor (Crayon/Klue industry pattern).
- **Contents:** per competitor — overview, their strengths, our strengths, landmines to set, objection counters, killer quote, scenario classification (GOLDEN / OFFENSIVE / DEFENSIVE / DISPLACEMENT). Plus the capability/positioning matrix (prospect-today vs each competitor vs prospect-with-Algolia, with `algolia_delta` business outcome per row).
- **Audience:** AE / SE.
- **Sales-cycle stage:** Discovery → competitive displacement / objection handling.

## 5. Leave-Behind — `{slug}/leave-behind.html` + `{slug}-leave-behind.pdf`

- **Purpose:** The only prospect-safe artifact. A 3-pager you can hand to the prospect.
- **Contents:** Search quality summary, anonymized competitive benchmark, top 3 recommendations, ROI summary, next steps. PDF must be >100KB, magazine-quality visuals (speedometer, tapered revenue funnel, annotated screenshots).
- **Audience:** Prospect.
- **Sales-cycle stage:** Post-meeting leave-behind / nurture.

## 6. Business Case / ROI Model — `{slug}-business-case.md`

- **Purpose:** The revenue justification. Every dollar figure must show its formula (`input × rate × factor = output`); estimates labeled `[ESTIMATE]`, facts `[FACT — source]`.
- **The 6 components** (each: status ACTIVE/CONDITIONAL, formula, conservative+moderate scenario, Algolia improvement range w/ source, AE fill-in prompt):
  1. **Search Conversion Lift** — `monthly_search_sessions × conversion_delta × AOV × 12`. Conservative +15%, moderate +20%.
  2. **Average Order Value Increase** — `search_orders/mo × AOV_delta × 12`. +5% / +10%. Active if personalization/merchandising gap.
  3. **Bounce Rate Reduction** — `visits × search_usage × bounce_delta × recovery_conversion × AOV × 12`. 10pp / 15pp reduction.
  4. **No-Results Recovery** — `searches × no_results_rate × AOV × recovery_rate × 12`. Baymard 34% benchmark. Active if typo/NLP gap.
  5. **Speed / Latency Gain** — Amazon "100ms = 1% revenue loss" benchmark. Active if latency gap.
  6. **Long-Tail Discovery** — `searches × nlp_fail_rate × AOV × recovery_rate × 12`. Active if semantic/NLP gap.
- **Scenarios:** Conservative total + Moderate total (each fully expanded), plus an **ASSUMPTION INVENTORY** listing every `[ESTIMATE]` the AE must replace with the prospect's real numbers (AOV, conversion, search-usage, no-results rate, etc.). Component activation is driven by which of the 10 scoring gaps are confirmed (`10-scoring-matrix.md` mapping at SKILL lines 102-114).
- **Audience:** AE/BDR (fill-in-the-blank tool to bring to the prospect).
- **Sales-cycle stage:** Discovery → business-case / executive justification. In the SPA this becomes the interactive ROI Calculator (4-6 levers, conservative/moderate toggle).

## 7. Strategic Signal Brief — `{slug}-strategic-signal-brief.md`

- **Purpose:** 1-page, signal-dense brief optimized for downstream LLM/CRM consumption (every line is standalone with full context, not narrative).
- **Contents:** 60-Second Story; Timing Signals (w/ source+date); In Their Own Words (speaker/title/quote/source/date); People (buying committee); Money (revenue, EBITDA margin zone, search ROI est); Search Gaps Found (gap/query/result/screenshot); Hiring Intelligence; Competitive Landscape; ICP-to-Priority Mapping; The Angle; Sources.
- **Audience:** LLM / CRM (and a fast human skim).
- **Sales-cycle stage:** Any — it's the machine-readable spine the other artifacts draw from.

## 8. ABX Campaign — `abx-campaign/` (10 files)

- **Purpose:** Full multi-touch outreach package, personalized from audit findings + exec quotes + competitor evidence. Campaign scope scales to signal tier (Tier 1 = full 5-email + LinkedIn + Loom, AE-led, within 48h; Tier 2 = 3-email, BDR-led; Tier 3 = email-1 + nurture, marketing).
- **Contents:** 5 emails (1-Hook=search gap finding; 2-Competitor=Golden Angle or Defensive; 3-Business Case=one ROI component; 4-Social Proof=vertical-matched case study; 5-Break-up), LinkedIn connect + 2 follow-ups (char-limited), 2-min Loom script (3 screenshots from disk), collateral-schedule (week-by-week touch plan).
- **Audience:** AE / BDR.
- **Sales-cycle stage:** Outreach / sequencing (before and between meetings).

## The Scored Output (the 10 search-area audit score)

From `algolia-audit-report/REFERENCE.md` Phase 3 (lines 46-90). 10 areas, each scored 0-10 with severity HIGH/MEDIUM/LOW, evidenced by a browser screenshot.

**Core areas (1-6):** Latency · Typo Tolerance · Query Suggestions/Empty State · Intent Detection · Merchandising Consistency · Content Commerce/Front-End UX.
**Algolia value-prop areas (7-10):** Semantic/NLP Search · Dynamic Facets & Personalization · Recommendations & Merchandising · Search Intelligence.

**Overall score:** weighted average where HIGH-severity areas get 2× weight, MEDIUM 1×, LOW 0.5× — `sum(score × weight) / sum(weight)`. The formula, all 10 inputs, and the calculation must be shown (reproducible/factcheckable). Critical-gap count = number of HIGH-severity areas. Rendered as a red/amber/green speedometer gauge (needle rotation `-90 + 180×score/10`; ≤4 red, 5-6 amber, ≥7 green).

Each gap area scoring <8 produces one **finding** (critical if HIGH+<5, moderate if MEDIUM+<8), each with: tested query, observed result, screenshot, impact stat (SAIM table), and a vertical-matched Algolia case study URL.

## The "Golden Angle" Concept

Defined in `algolia-intel-competitors/SKILL.md` (lines 51-86). The Golden Angle = **at least one of the prospect's competitors is already an Algolia customer with public, verified proof.** It is the single strongest competitive wedge: "Your competitor X solved this exact problem with Algolia and got Y."

- **How detected:** BuiltWith + network verification per competitor; if a competitor uses Algolia, WebFetch `algolia.com/customers/{slug}` for the verbatim metric. A vertical-wide Algolia customer sweep runs even when no direct competitor uses Algolia (≥3 entries target).
- **Competitive scenario taxonomy:** GOLDEN (competitor uses Algolia w/ proof) · DEFENSIVE (prospect already on Algolia, expansion) · OFFENSIVE (competitors have inferior search, Algolia = moat) · MIXED.
- **How presented:** a full-width amber/gold **Golden Angle Banner** hero callout (IA Section 5) — company name, result achieved, case study link. It also drives `recommended_first_play` (type=competitive), ABX email 2, and the playbook BLUF top angle. If no Golden Angle, the system falls back to the Defensive play and never fabricates competitor tech.

## Implications for the AE UI

The PRISM IA (`docs/specs/information-architecture-v2.md`) already maps every deliverable above to a 6-tab dashboard (Overview / Research / Search Audit / Business Case / Competitive Intel / Sales Actions) over a Next.js + assistant-ui stack. Two design decisions matter for the AE journey:

### A. The 60-second brief — its source content

IA Section 1 (Overview) is explicitly "60-second pre-call brief — everything the AE needs before walking into a meeting." Its source content should be pulled from the artifacts that are *already distilled for speed*, not the long-form report:

1. **Playbook BLUF header** (`{slug}-playbook.md`) — signal tier, top angle, key exec, partner play, most-urgent dated signal. This IS a 30-second read by design. **Primary source for the brief.**
2. **Strategic Signal Brief → "60-Second Story"** + Money block (score, ROI est, margin zone). Machine-dense, perfect for tiles.
3. **Score gauge + critical-gap count** from `10-scoring-matrix.md` (speedometer + top-3 gaps).
4. **One-line pitch** from the business case AE Talking Point.
5. **Factcheck verdict** (PROCEED/WARN/BLOCKED) as a traffic-light badge.

The brief should NOT try to summarize the full audit report inline — it should surface the already-compressed BLUF and Signal Brief, with everything else one click away.

### B. The drill-to-artifact set

These are the artifacts an AE drills into from the brief, in deal-stage order:

| Drill target | Artifact | Why it's the drill-down |
|---|---|---|
| Pre-call prep | **AE Playbook** (talking points, SPIN discovery, MEDDPICC, objections, power map) | The core pre-call/discovery artifact. Maps cleanly to IA Section 6 (Sales Actions). |
| Evidence | **10-dimension Search Audit** + findings w/ annotated screenshots | The proof behind the score. IA Section 3. |
| Justification | **Business Case ROI** (6 components, conservative/moderate, fill-in prompts) | Interactive ROI calculator. IA Section 4. The AE fill-in prompts are the key interaction — let the AE replace `[ESTIMATE]`s live. |
| Competitive wedge | **Golden Angle banner + Battle Cards + competitive matrix** | THE differentiator (IA calls Section 5 "the differentiator"). Golden Angle is the highest-conviction opening. |
| Outreach | **ABX campaign** (emails / LinkedIn / Loom, tier-scaled) + **Leave-Behind PDF** | Ready-to-send collateral. IA Section 6. Copy-to-clipboard per touch. |
| Live meeting | **SPA `index.html`** | The screen-share surface. |

### C. Design principles inherited from the deliverables

- **Provenance everywhere.** Every artifact enforces source URLs on every data point (the AE report requires inline hyperlinks; the business case requires a formula per number). The UI must show provenance inline (`.inline-src` pills) and never strip it on internal views — but the ABX SPA view must strip source notes from sendable email copy.
- **Exec-language grounding is the moat.** Talking points and discovery questions use the prospect's verbatim earnings-call language. The "Speaking Their Language" / "In Their Own Words" / "Said vs Found" pattern recurs across the playbook, report, and business case — the UI should make these quotes copy-to-clipboard and pair each with the contradicting audit finding.
- **Signal tier drives everything.** HOT/WARM/COLD (and ACT NOW/MONITOR/WATCH) gates campaign scope and the recommended first play. The AE UI should lead with the signal tier and `recommended_first_play`.
- **Golden Angle is conditional but top-priority when present** — render as a hero banner, route it into the brief's top angle.
